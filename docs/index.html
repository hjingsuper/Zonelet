把世界时间，
安静地放在菜单栏。

为每个城市选择自己的日期与时间格式。
无需账户，不联网，没有多余功能。

专注于时区与时间显示本身。

01

每个时区，各自合适

时间、日期、星期和 ISO 格式，每个城市都可以不同。

UTC06:3524 小时 纽约02:35:20带秒 东京2026-09-02 15:35 周三日期时间 + 星期
02

统一设置，也能单独调整

底部一键应用到全部时钟，之后仍可修改任意一行。

统一格式完整日期 + 时间⌄
纽约日期时间 + 星期⌄

03

菜单栏，一眼分清

纤细分隔符让多个时区清楚而不拥挤。

04

完全离线

使用系统时间与 macOS 时区数据。无账户、无网络、无分析。

小而美，也完全开放。

免费下载。MIT 开源。每一次正式发布，都有可验证的 macOS 安装包。

Zonelet
功能 安装 开源 GitHub

把世界时间，
安静地放在菜单栏。

为每个城市选择自己的日期与时间格式。
无需账户，不追踪，没有多余功能。

下载 Apple 芯片版 查看 GitHub

需要 macOS 14 或更高版本

打开就会用。

三步完成安装，之后 Zonelet 会安静地留在菜单栏。

  1. 1

    打开 DMG

    下载完成后，双击 Zonelet-Apple-Silicon.dmg。

  2. 2

    拖入“应用程序”

    把 Zonelet 图标拖到右侧的“应用程序”文件夹。

  3. 3

    首次打开

    前往“应用程序”打开 Zonelet。它默认只显示 UTC，并驻留菜单栏。

首次打开需要允许

Zonelet 是免费开源项目，目前没有 Apple Developer 证书。请只使用本官网或 GitHub Releases 下载的安装包，然后前往“系统设置 → 隐私与安全性”，在安全性区域找到被阻止的 Zonelet，点击“仍要打开”，再按提示确认。

从旧版升级到 v1.12 后，Zonelet 会自动迁移已有地区时间和格式设置，并使用新的正式应用标识避开 macOS 26 可能残留的菜单栏阻止状态。如果仍未显示，请前往“系统设置 → 菜单栏 → 允许在菜单栏显示”，确认 Zonelet 已开启。

刚刚好，就这些。

专注于不同地区的时间显示。

01

每个地区，各自合适

时间、日期、星期和 ISO 格式，每个城市都可以不同。

UTC06:3524 小时 纽约02:35:20带秒 东京2026-09-02 15:35 周三日期时间 + 星期
02

统一设置，也能单独调整

底部一键应用到全部时钟，之后仍可修改任意一行。

统一格式完整日期 + 时间⌄
纽约日期时间 + 星期⌄
UTC24 小时⌄
UTC 06:35│ 纽约 02:35│ 东京 15:35
03

菜单栏，一眼分清

纤细分隔符让多个地区时间清楚而不拥挤。

04

安静启动，自动更新

开机自启默认开启，失败时可以重新检测；启动时不弹出主界面。新版会在后台下载、安装并重新启动。

隐私清楚可见

地区时间换算完全使用系统数据；只有检查软件更新时会连接 GitHub Releases。无账户、无分析、无追踪。

小而美，也完全开放。

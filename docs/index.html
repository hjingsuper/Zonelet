Just enough

少一点功能，
多一点清楚。

Zonelet 只做好一件事：让不同地区的时间，在你需要时立刻可见。

01

菜单栏，就是答案

多个地区以纤细分隔符排列。无需打开窗口，也能快速确认此刻时间。

02

每个地区，独立格式

24 小时、12 小时、日期、星期与秒数，统一设置或逐项调整都可以。

03

时差直接看懂

同时显示相对本机与 UTC 的小时差，不再靠心算跨越时区。

04

安静地留在后台

可选开机自启，启动时不弹主界面；支持从 GitHub 检查并安装更新。

安装指南

三步安装。
没有隐藏步骤。

Zonelet 暂无 Apple Developer 证书，因此首次打开需要在系统设置中手动允许。安装包由开源代码自动构建，并由 Sparkle 签名校验更新。

  1. 01

    打开 DMG

    双击下载的 Zonelet-Apple-Silicon.dmg。

  2. 02

    拖入“应用程序”

    在安装窗口中，将 Zonelet 拖到“应用程序”文件夹。

  3. 03

    允许首次打开

    前往“系统设置 → 隐私与安全性”，找到被阻止的 Zonelet，点击“仍要打开”。

如果菜单栏没有出现

前往“系统设置 → 菜单栏 → 允许在菜单栏显示”，开启 Zonelet。默认仅添加 UTC；其他地区由你自行选择。

Local first

你的时间，
只在你的 Mac 上。

地区时间换算完全使用 macOS 自带的时区数据库。Zonelet 不需要账户，不收集使用数据，也没有分析或广告服务。

只有在检查软件更新时，应用才会连接 GitHub Releases。
